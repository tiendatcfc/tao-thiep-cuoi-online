# HPWD Phase 0 + 1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Người dùng đăng nhập, chọn 1 trong 5 mẫu thiệp, chỉnh sửa bằng editor theo section, và publish thiệp cưới hoàn chỉnh (không watermark) tại `/i/{slug}` với QR mừng cưới, album, lời chúc, RSVP, nhạc nền và hiệu ứng mở phong bì.

**Architecture:** Monorepo pnpm + Turborepo. `apps/web` (Next.js 15 App Router) chứa cả editor lẫn trang thiệp public SSR. `packages/schema` (Zod) là nguồn sự thật duy nhất cho InvitationDocument. `packages/db` (Prisma + PostgreSQL). Draft và bản publish tách riêng (`document` vs `publishedDocument`).

**Tech Stack:** Next.js 15, React 19, TypeScript strict, Prisma 6 + PostgreSQL 16, Auth.js v5, Zustand, dnd-kit, framer-motion, Zod, sharp, Cloudflare R2 (S3 API), Redis (rate limit), vitest + @testing-library/react.

**Spec:** `docs/superpowers/specs/2026-08-10-wedding-invitation-builder-design.md` — đọc trước khi làm bất kỳ task nào.

## Global Constraints

- Node ≥ 22, pnpm ≥ 9. TypeScript `strict: true` toàn repo.
- Toàn bộ copy hiển thị cho người dùng bằng **tiếng Việt**.
- Mobile-first: thiết kế trang thiệp ở viewport 390px; editor preview mặc định khung mobile.
- Mọi đọc/ghi InvitationDocument phải qua `InvitationDocumentSchema.parse()` từ `@hpwd/schema` — không định nghĩa lại type ở nơi khác.
- Không bao giờ render watermark; badge footer bật/tắt bằng `settings.showBadge`.
- Không autoplay nhạc trước tương tác người dùng.
- Slug: regex `^[a-z0-9-]{3,60}$`.
- Test runner: `pnpm vitest run` tại root (Turborepo pipe). Commit sau mỗi task, message tiếng Anh theo conventional commits.

- [ ] **Step 3:** Implement:

```ts
export function crc16ccitt(input: string): string {
  let crc = 0xffff
  for (const ch of Buffer.from(input, 'utf8')) {
    crc ^= ch << 8
    for (let i = 0; i < 8; i++) crc = crc & 0x8000 ? ((crc << 1) ^ 0x1021) & 0xffff : (crc << 1) & 0xffff
  }
  return crc.toString(16).toUpperCase().padStart(4, '0')
}
const tlv = (tag: string, value: string) => tag + String(value.length).padStart(2, '0') + value

export function buildVietQRPayload(opts: { bankBin: string; accountNumber: string; amount?: number; message?: string }) {
  const merchantInfo = tlv('00', 'A000000727')
    + tlv('01', tlv('00', opts.bankBin) + tlv('01', opts.accountNumber))
    + tlv('02', 'QRIBFTTA')
  let p = tlv('00', '01') + tlv('01', opts.amount ? '12' : '11') + tlv('38', merchantInfo) + tlv('53', '704')
  if (opts.amount) p += tlv('54', String(opts.amount))
  p += tlv('58', 'VN')
  if (opts.message) p += tlv('62', tlv('08', removeDiacritics(opts.message).slice(0, 25)))
  p += '6304'
  return p + crc16ccitt(p)
}
```

  `removeDiacritics` dùng `str.normalize('NFD').replace(/[̀-ͯ]/g, '').replace(/đ/g, 'd').replace(/Đ/g, 'D')` — đặt trong `apps/web/src/lib/slug.ts` cùng hàm `toSlug()` (tái dùng ở Task 17).
